# Say that src/scanner.c is hand-written, not generated

`AGENTS.md` (and the repo notes in `agent-feedback/README.md`) say everything under `src/` is generated by `tree-sitter generate` and must never be hand-edited. `src/scanner.c` is the hand-written external scanner that ports htmljs-parser, and almost every parser sync is an edit to it; read literally, the rule forbids the repo's main kind of change. Name it as the exception: `grammar.js` and `src/scanner.c` are the sources, `src/grammar.json`, `src/node-types.json`, `src/parser.c` and `src/tree_sitter/` are generated.

Check: edit `src/scanner.c`, run `pnpm run generate`, and `git status` still shows the edit; the file's header calls itself a port of htmljs-parser's state machine.
